### Recommended Plugins:

| Name                        | Notes                                                                               |
| --------------------------- | ----------------------------------------------------------------------------------- |
| Advanced API                | Needed for other plugns to work                                                     |
| Discord Alert               | Great alternative to Ground Station with more control and one that works more often |
| Ground Station              | Very strong notification plugin. Note: I have issues with this being consistent     |
| Hocus Focus                 | must have for focusing                                                              |
| Livestack                   | Fun optional app if you want to do EAA within NINA                                  |
| Log Viewer                  | Great for troubleshooting                                                           |
| Night Summary               | neat summary sent to you at the end of your session. Great for remote.              |
| Orbitals                    | Want to image solar system objects (including comets)?                              |
| Phd2 Tools                  | Enables certain instructions in the sequencer                                       |
| Point3D                     | Neat Telescope orientation display tool                                             |
| Sequencer+                  | Necessary to access extra instructions, functions, and loops                        |
| Shutdown PC                 | Only needed if you want to add a shutdown instruction to your sequence              |
| Synchronization             | Necssary if you're controlling multiple cameras from one computer and mount         |
| Target Planning             | Easy way to plan for specific targets                                               |
| Target Scheduler            | Required for automating remote and unattended imaging                               |
| Three Point Polar Alignment | Necessary to achieve proper PA. only needed once in a while at a remote site        |
| Touch 'N' Stars             | Great for controlling and monitoring from your phone                                |
| WandererAstro Tools         | Only if you use a Wanderer Astro Device                                             |

## Contributing

Contributions are welcome! If you'd like to add a manufacturer, driver, software link, or correct existing information:

3. Make your edits (add or update entries, fix broken links, etc.).
